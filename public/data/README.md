# Bangladesh district map data

District/division names: https://github.com/ifahimreza/bangladesh-geojson
(retrieved 2026-10-21), ODbL 1.0; see LICENSE-ODbL.txt. Common English
spellings have been normalized. The derived name database is available in
bangladesh-districts.json under ODbL 1.0.

Boundaries: geoBoundaries gbOpen BGD ADM2, Bangladesh Bureau of Statistics
(BBS) / OCHA ROAP, CC BY 3.0 IGO.
https://www.geoboundaries.org/api/current/gbOpen/BGD/ADM2/
https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/BGD/ADM2/geoBoundaries-BGD-ADM2_simplified.geojson
https://creativecommons.org/licenses/by/3.0/igo/
Geometries simplified to 0.004 degrees and projected into SVG coordinates.
Map is illustrative and is not intended for navigation.
